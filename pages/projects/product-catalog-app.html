Touchscreen product catalog application

Commercial application created using Unity engine

Overview

This application is a product‑presentation platform designed to showcase the company’s machinery in an intuitive, interactive way. Its core feature is a scrollable product carousel, allowing users to browse through the full catalog of machines, leading the user to a dedicated machine page containing essential technical information, such as full technical overview, including a parametric specification table with performance values, photo and media gallery and complete documentation displayed directly through an embedded PDF viewer.

Features

  • 3D Interactive carousel

    A scrollable, interactive slider showing all 3D machine models.

  • Machine details page

    Each model have a separate page dedicated for technical product details, video and photo gallery, tables with parametric specifications and PDF viewer with full product documentation.

  • Localization

    Application supports seamless transition between two selected languages.

Contribution

During development, I worked on:


  • Restructuring the old localization system and migrating to new localization system,
  • Dynamic creation of parametric tables in UI, based on .csv files,

    Google Sheets were used to create customizable parametric tables. Based on the data stored in .csv files, the system dynamically generated the table UI, supporting different table layouts, numbers of rows, columns, sub-columns, and row-specific data. One .csv defined the table structure, including layout, row IDs and text alignment, while a second .csv assigned values and units to each row ID. Since the .csv files were stored in Streaming Assets, the data and table layout could be modified even after the application was built. As a result, the dynamic UI was automatically updated based on changes made to the files.
