Vending machines product appliaction

Commercial Mixed Reality application created using Unity engine

Overview

Mixed Reality application that enables realistic visualization of safety and tool vending machines directly in their intended environment. Designed for use with Meta Quest 3 headsets, the solution serves as a sales tool and product configurator for field representatives.

Features

  • Device selection

    The user starts by selecting one of several available vending machine types. They can then choose a specific variant of the model—based on size or purpose. Once the device is placed in real space using Mixed Reality mode, users can add or remove functional modules depending on their needs.

    Device selection

    Additional modules

  • Appearance customization and technical data

    The application also allows for color customization, based on predefined schemes (if supported by the selected model). Users can browse descriptions and technical specifications for the device and its components, giving potential buyers a comprehensive understanding of the product before making a decision.

    Customization panel

    Green color

  • Interactive interior and operation simulation

    The 3D models include a detailed interior of the vending machines. Users can open the device’s door and view the compartment layout, item dispensing system, and slot arrangement. The front touchscreen panel is also interactive - demonstrating the item dispensing flow step by step. This allows users to experience the device’s functionality without needing physical access.

    Vending machines lockers

    Touchscreen panel

  • Space measurement and real-world placement

    In Mixed Reality mode, the machine can be placed in an actual office, warehouse, or production space. The app supports simple measurements, helping determine whether the selected model fits within the available space. This feature ensures that the chosen configuration aligns with the customer’s real-world environment.

  • Virtual workbench

    The application includes a virtual workbench containing primitive 3D shapes whose dimensions can be freely adjusted, allowing them to be fitted to any real-world object. While manipulating the shapes, the workbench indicates whether the given object would fit into one of the vending machine's lockers.
