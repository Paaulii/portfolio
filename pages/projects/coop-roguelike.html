Multiplayer Coop Roguelike

Personal project made on Unreal Engine 5

Overview

This project is currently in development stage.


Multiplayer coop roguelike game set in a mine, where players need to defend their minecart with a payload from monsters. They also can explore mysterious caves and mine stones to obtain crystals and coins. Crystals can be used to power-up minecart to move quicker on the railroad. Each level contains of boss fight, after which players gain XP and coins to upgrade themselves and minecart for further adventures. 💎⛏️

Features

  • Creating and joining session

    The UI System is a World Subsystem responsible for managing the main UI layer and the stacks required to support Common UI and initialization of global View Models. It uses a configurable Data Asset to determine which ViewModels (VMs) should be created for a given level. The subsystem’s lifetime is tied to the level, allowing ViewModels to be created and managed only when they are needed. Any UI can access and bind to the ViewModels it requires.

  • Creating and joining session
  • Prototype of a game loop

    The main game loop handles creating and joining session, spawning AI camps in the map, and minecart movement. When the payload reaches the end of the route, the boss fight begins. Boss is spawned, and the UI displays the boss’s health status. After defeating a boss, UI with victory screen is displayed. If players die during the fight, they can retry the level.

  • Health bars

    In the game, players, AI, resources and minecart have their own health bar status. They are displayed based on priority: Owner Player > Other Player > AI > Minecart > Resources. Later, I plan to display it based on the distance from the player.

  • UI System

    The UI System is a World Subsystem responsible for managing the main UI layer and the stacks required to support Common UI and initialization of global View Models. It uses a configurable Data Asset to determine which ViewModels (VMs) should be created for a given level. The subsystem’s lifetime is tied to the level, allowing ViewModels to be created and managed only when they are needed. Any UI can access and bind to the ViewModels it requires.

  • Managers

    Managers in the game are created in Game Mode as a subclass of AInfo

  • AI

    Simple AI that tries to attack the player, if no players are around then it focuses the minecart, and if no minecart are in a range then it patrols a location.

  • Boss Fight Sequence

    When the minecart reaches the end of the railroad, boss's spawns. UI with Boss's health is shown and players need to kill the boss in order to complete the level and gain awards.

  • Abilities

    Players at the moment can: attack, revive a companion, mine stones, pick up, drop and use item.
